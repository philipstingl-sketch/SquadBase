SQUAD BASE v2.5
================
Zusätzliche Funktionen: Live-CPU/RAM/GPU-Zeitverlauf, Reaktions-Soundeffekte,
Cube Rush mit Kristall-Wiederbelebung und progressiven Levels/Tempo, lokaler
Hilfeassistent und optional Ollama für echte KI-Antworten, zwei selbst komponierte
OGG-Soundtracks plus Musikleiste.

Source: Go 1.22+ (go build ./...), Frontend als eingebettete statische Assets.
Die Windows-EXE ist unsigniert. Windows Smart App Control kann sie blockieren.
Keine Administratorrechte nötig, keine Anleitung zum Ausschalten von Schutz.

ALTE FUNKTIONEN: siehe README.txt und SquadBase_v2.5_Anleitung.txt.
